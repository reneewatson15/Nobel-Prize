Approach

For this assignment, I plan to use the Nobel Prize organization’s public APIs to explore patterns in Nobel Prize awards and laureates. I will retrieve the data in JSON format using R and the jsonlite package. Since the API data contains nested information, I will use purrr and dplyr from the tidyverse to organize the records into tidy data frames. I will create separate tables for prize records, laureate information, and individual laureate awards, then join the tables when needed for comparisons. I plan to investigate four questions: 1. Which Nobel Prize category has awarded the most prizes? 2. Which decade had the highest number of individual Nobel laureate awards? 3. Which Nobel Prize category has the highest percentage of female laureates? 4. Which Nobel Prize category has the highest median age among recipients?

Some challenges I anticipate include working with nested JSON fields, accounting for laureates who have received more than one award, and distinguishing individual laureates from organizations. I will also need to check for missing birth dates when estimating recipient’s ages. Because the age calculation uses birth year and award year, the ages will be approximate. For the decade comparison, I will note that the 2020s are not yet complete. I will use summary tables to present the findings and explain what each result means.

The API returns data in pages. The function below retrieves every page, so the analysis is not limited to the first 25 or 1,000 records. simplifyVector = FALSE preserves the nested JSON structure while the data are being read.

base_url <- "https://api.nobelprize.org/2.1"

get_all_records <- function(endpoint, field, page_size = 1000) {
  all_records <- list()
  offset <- 0

  repeat {
    url <- paste0(
      base_url, "/", endpoint,
      "?limit=", page_size, "&offset=", offset
    )

    response <- jsonlite::fromJSON(url, simplifyVector = FALSE)
    page <- response[[field]]

    if (is.null(page) || length(page) == 0) break

    all_records <- c(all_records, page)

    if (length(page) < page_size) break
    offset <- offset + page_size
  }

  all_records
}

prizes_json <- get_all_records("nobelPrizes", "nobelPrizes")
laureates_json <- get_all_records("laureates", "laureates")

Some JSON properties are missing for certain records, particularly for organizations. This helper converts a missing value into NA.

get_text <- function(x) {
  if (is.null(x) || length(x) == 0) {
    NA_character_
  } else {
    as.character(x[[1]])
  }
}


prizes <- purrr::map_dfr(prizes_json, function(x) {
  tibble(
    award_year = as.integer(x$awardYear),
    category = get_text(x$category$en),
    recipients = length(x$laureates)
  )
})


laureates <- purrr::map_dfr(laureates_json, function(x) {
  tibble(
    laureate_id = as.character(x$id),
    name = coalesce(
      get_text(x$knownName$en),
      get_text(x$orgName$en),
      get_text(x$fullName$en)
    ),
    gender = get_text(x$gender),
    birth_date = get_text(x$birth$date)
  )
})

laureate_awards <- purrr::map_dfr(laureates_json, function(x) {
  purrr::map_dfr(x$nobelPrizes, function(p) {
    tibble(
      laureate_id = as.character(x$id),
      award_year = as.integer(p$awardYear),
      category = get_text(p$category$en)
    )
  })
}) %>%
  distinct(laureate_id, award_year, category)

individual_awards <- laureate_awards %>%
  left_join(laureates, by = "laureate_id") %>%
  filter(gender %in% c("male", "female"))

Question 3: Which Nobel Prize category has the highest percentage of female laureates?

I compare gender and prize category using the individual laureate records. I count each person only once per category, even if that person received more than one prize in that category. Organizations are excluded because they are not individual men or women.

gender_by_category <- individual_awards %>%
  distinct(laureate_id, category, gender) %>%
  group_by(category) %>%
  summarise(
    women = sum(gender == "female"),
    total_individuals = n(),
    female_percent = round(100 * women / total_individuals, 1),
    .groups = "drop"
  ) %>%
  arrange(desc(female_percent))

Question 4: Which Nobel Prize category has the highest median age among recipients?

This question requires combining information from different fields. I join each person’s birth date to their Nobel Prize award year using laureate_id. I then subtract the birth year from the award year and compare the median estimated age across categories. The ages are estimates based on birth year and award year rather than exact dates, and recipients with missing birth information are excluded from the analysis.

ages_at_award <- individual_awards %>%
  mutate(
    birth_year = as.integer(substr(birth_date, 1, 4)),
    estimated_age = award_year - birth_year
  ) %>%
  filter(
    !is.na(estimated_age),
    between(estimated_age, 0, 120)
  )

age_by_category <- ages_at_award %>%
  group_by(category) %>%
  summarise(
    laureate_awards = n(),
    median_age = round(median(estimated_age), 1),
    mean_age = round(mean(estimated_age), 1),
    .groups = "drop"
  ) %>%
  arrange(desc(median_age))
